# 오산 헤리티지자이 Premium Digital Model House — V2

GitHub Pages 배포용 정적 웹사이트입니다.

## 업로드
저장소 루트에 `index.html`, `css/`, `js/`, `images/`를 업로드한 뒤
Settings → Pages → Deploy from a branch → main → /(root) → Save.

## 포함
- 프리미엄 Hero
- 브랜드/1,783세대
- 프리미엄 6개 포인트
- 입지
- 양산4지구 미래가치 타임라인
- 단지/커뮤니티
- 분양정보
- FAQ
- 상담예약 데모
- 모바일 고정 CTA

## 중요
실제 분양 광고에 사용하는 분양가·청약자격·일정·개발계획·커뮤니티 시설·연락처 등은 최신 공식자료로 교체해야 합니다.

## 업로드 시 가장 중요한 점
GitHub 저장소의 최상위에 `index.html`, `css`, `js`, `images`가 바로 보여야 합니다. `osan-heritage-xi-v2_1/` 같은 바깥 폴더를 한 번 더 올리면 안 됩니다.
